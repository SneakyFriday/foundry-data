## Installation

1. Copy this link and use it in Foundrys module manager to install the module
    > https://gitlab.com/henry4k/foundryvtt-lang-de/-/raw/master/module.json
2. Enable the module in your worlds module settings
3. Choose "German" as language in your world settings


## Rationale (in german)

- Token => Figur
- Combat Encounter => Begegnung
    - Nicht jede Begegnung, bei der rundenbasiert Vorgegangen wird, muss ein Kampf sein
- Sound => Titel
-   - Nur solange es sich um Audio handelt, was über den Wiedergabelisten-Reiter verwaltet wird
-   - Geräusch ist an dieser Stelle eine unpassende Übersetzung, da es bspw. nicht gut auf Musik passt
    - TODO: Seit v12 unterscheidet Foundry zwischen Umgebungsgeräuschen und Musik, d.h. eine passendere Bezeichnung ist ggf. Möglich
- Ambient Light => Lichtquelle
    - Umgebungslicht wird üblicherweise für allgegenwärtiges Licht verwendet (Siehe auch [Wikipedia](https://en.wikipedia.org/wiki/Shading#Ambient_lighting))
- Shape => Form
- Template Shape => Schablone
- Backup => Sicherung
- Filter X => X durchsuchen
- Configure X => X anpassen
- Create X => X erstellen
- Tile => Kachel
